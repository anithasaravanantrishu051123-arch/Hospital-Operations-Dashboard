# Hospital Operations Dashboard – Power BI


## Project Overview
This project focuses on analyzing hospital operations using Power BI to support better operational decision-making.

## Business Objectives
- Analyze patient admission trends.
- Monitor department-wise performance.
- Identify waiting time patterns.
- Track hospital billing and revenue.
- Understand patient flow and length of stay.

## Key KPIs
- Total Admissions
- Average Waiting Time
- Total Billing Amount
- Average Length of Stay
- Total Doctors

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modelling

## Dashboard Pages
- Hospital Operations Overview
- Department Performance Analysis
- Patient Admission and Waiting Time Analysis

## Key Learning
Developed practical experience in data modelling, KPI development, dashboard design, and operational data analysis.
